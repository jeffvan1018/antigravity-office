# Generate Furniture Sprite

Use this skill to assemble a structured image-generation prompt for isolated 16-bit point-and-click adventure game furniture sprites on a chromakey magenta background, then key out the background using the bundled Pillow script so only the final transparent PNG is saved.

## Prompt Template

Always construct the prompt using the following exact 7-field structure. Preserve the fixed defaults verbatim, and merge user-provided details into `subject`, `details`, and `palette` as needed so the sprite matches rooms created with `generate-background-image`.

```text
style: 16-bit pixel art, chunky retro VGA pixel density matching 2D adventure game backgrounds, crisp pixel edges, clean dark pixel outline
perspective: flat straight-on front elevation view with slight top-down surface depth, flat horizontal base to sit flush on a single-point perspective floor, classic 2D point-and-click adventure game foreground prop
subject: <single furniture piece or prop>, isolated standalone object, no characters, no NPCs
details: <materials, proportions, surface items, and functional details; soft even overhead interior lighting>
palette: <color scheme matching target room aesthetic, avoid magenta or hot pink>
background: solid flat pure chromakey magenta (#FF00FF) background, uniform flat color, no room, no floor, no wall, no cast ground shadow, no gradient
output: isolated game sprite only, centered with clean silhouette and generous margin
```

## Room Compatibility Guidelines

Sprites must drop cleanly onto the unobstructed lower-third walkable floor of rooms generated by `generate-background-image`:

- **Flat Base (No Isometric Angles)**: Always keep the bottom edge flat and horizontal so counters, tables, desks, and chairs sit flush against the straight-on elevation floor and baseboard without perspective clash.
- **Matching Pixel Density**: Use chunky 16-bit VGA pixel art rather than high-resolution or overly fine pixel detail so the sprite's texel size matches the room walls and floor.
- **Even Lighting**: Use soft, even overhead/front interior lighting with no harsh directional shadows so the prop blends into any room.
- **Room Palette Presets** (pick the one matching the target background, and avoid magenta/hot pink):
  - **Cozy Cafe**: Warm espresso browns, honey oak, cream, terracotta, and brushed brass.
  - **Google Corporate Office / Conference Room**: Crisp whites, cool slate grays, light oak wood, matte black frames, and subtle primary-color accents (blue, red, yellow, green).
  - **Google Server Room**: Matte black, brushed steel, cool slate gray, and subtle cyan/green indicator accents.

## Field Guidelines

- **Fixed fields (`style`, `perspective`, `background`, `output`)**: Keep these exact values unless the user explicitly asks to override them. Using `#FF00FF` chromakey magenta with no ground shadow ensures clean automated transparency extraction.
- **`subject`**: Describe the single furniture item or prop requested by the user (e.g., `wooden espresso bar counter`, `modern conference table`, `ergonomic office chair`, `rolling whiteboard`), then always append `isolated standalone object, no characters, no NPCs`.
- **`details`**: Specify materials, textures, and small attached props while keeping the object self-contained.
- **`palette`**: Match the target environment—for example, warm espresso browns, creams, and brass for a cozy cafe, or crisp whites, slate grays, light oak, and primary-color accents (blue, red, yellow, green) for a Google corporate office. Avoid magenta/hot pink in the sprite itself so it does not conflict with the chromakey background.

## Workflow

1. Gather the furniture/prop requirements from the user (what item it is, which room style it belongs to, and any specific materials or props on it).
2. Fill in the 7-field prompt template above.
3. Invoke the `image-generator` subagent (`TypeName: "image-generator"`) with:
   - The assembled 7-field prompt as the brief.
   - A square or item-appropriate aspect ratio (e.g., `1:1` for chairs, desks, or compact props; `16:9` or `4:3` for wide items like bars, counters, or long conference tables).
4. Convert the generated chromakey image from the artifact path returned by `image-generator` directly into the final transparent PNG at `creative/sprites/<sprite-slug>.png` (or the user-specified path) using [`make_transparent.py`](./scripts/make_transparent.py), scaling it with `--target-height` (using nearest-neighbor resampling) so it drops directly into a `1376x768` room background without manual resizing:
   ```bash
   python3 .agents/skills/generate-furniture-sprite/scripts/make_transparent.py "<artifact-image-path>" "creative/sprites/<sprite-slug>.png" --trim --target-height <px>
   ```
   **Target Height Guide for `1376x768` Rooms** (where doorways are ~`380-420px` tall and the walkable floor is ~`260px` tall):
   - **Small props** (plants, trash bins, stools, side tables): `100`–`140` px
   - **Chairs & low tables** (office chairs, cafe tables, coffee tables): `130`–`170` px
   - **Bare counters / desks** (without tall items on top): `140`–`170` px
   - **Counters with equipment** (e.g., coffee counter with espresso machine on top): `210`–`250` px
   - **Tall standing equipment** (printers, water coolers, vending machines, tall bookshelves): `240`–`320` px
   (Adjust `--tolerance` if needed.)
5. Inspect the final transparent PNG with `read_file` to verify crisp 16-bit pixel art edges, clean transparency with no magenta halo, a flat horizontal base, and pixel density/palette cohesion with the target room background.
