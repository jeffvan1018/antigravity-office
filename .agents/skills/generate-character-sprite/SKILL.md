# Generate Character Sprite

Use this skill to assemble a structured image-generation prompt for a 2-frame forward-facing idle character sprite on a chromakey magenta background, then key out and align both frames into a transparent 2-cell PNG sprite sheet using the bundled Pillow script.

## Prompt Template

Always construct the prompt using the following exact 8-field structure. Preserve the fixed defaults verbatim, and merge user-provided details into `subject`, `details`, and `palette` as needed so the character matches rooms created with `generate-background-image`.

```text
style: 16-bit pixel art, chunky retro VGA pixel density matching 2D adventure game backgrounds, crisp pixel edges, clean dark pixel outline
perspective: strictly flat straight-on front elevation view (0-degree rotation, facing directly forward toward the viewer), classic 2D point-and-click adventure game character sprite
layout: horizontal 2-frame sprite sheet arranged side by side with generous spacing (left frame: neutral standing idle pose; right frame: subtle breathing or weight-shift idle pose), identical character scale and proportions in both frames
subject: <character description>, full body head to toe, standing upright facing forward
details: <outfit, hair, accessories, and subtle pose difference between the two idle frames; soft even overhead interior lighting>
palette: <color scheme matching target room aesthetic, avoid magenta or hot pink>
background: solid flat pure chromakey magenta (#FF00FF) background, uniform flat color, no room, no floor, no wall, no cast ground shadow, no dividing lines, no grid borders, no labels
output: clean 2-frame horizontal idle sprite sheet only, both frames aligned on the same horizontal ground line
```

## Room Compatibility & Sizing Guidelines

Sprites must drop cleanly onto the `1376x768` rooms generated by `generate-background-image` and match the `generate-furniture-sprite` scale:

- **Proportional Character Height**: Default `--char-height 280` px (recommended `260`–`290` px for adult characters in `1376x768` rooms, where doorways are ~`380–420` px tall and chairs/desks are `150` px tall).
- **2-Cell Alignment**: [`make_character_sheet.py`](./scripts/make_character_sheet.py) splits the two frames, scales both uniformly with `NEAREST` resampling, centers each frame horizontally in its cell, and places the character's **feet flush on the bottom edge** of each cell.
- **Avoid Magenta / Hot Pink**: Never use magenta or hot pink in clothing, hair, or accessories so chromakey extraction stays clean.

## Workflow

1. Gather the character requirements from the user (role/archetype, outfit, colors, accessories, and any height override).
2. Fill in the 8-field prompt template above.
3. Invoke the `image-generator` subagent (`TypeName: "image-generator"`) with:
   - The assembled 8-field prompt as the brief.
   - Aspect ratio `16:9` or `4:3` so both side-by-side standing frames have plenty of horizontal room and separation.
4. Convert the generated chromakey image from the artifact path returned by `image-generator` directly into the final transparent 2-cell PNG at `creative/sprites/<character-slug>.png` (or the user-specified path) using [`make_character_sheet.py`](./scripts/make_character_sheet.py):
   ```bash
   python3 .agents/skills/generate-character-sprite/scripts/make_character_sheet.py "<artifact-image-path>" "creative/sprites/<character-slug>.png" --char-height 280
   ```
   (Use `--cell-width` / `--cell-height` if your engine expects fixed cell dimensions; adjust `--tolerance` if needed.)
5. Inspect the final transparent 2-cell PNG with `read_file` and verify its dimensions (width = `2 * cell_w`), confirming crisp 16-bit pixel edges, no magenta halo, two distinct forward-facing idle poses, horizontal centering in each cell, and feet resting on the bottom edge.
